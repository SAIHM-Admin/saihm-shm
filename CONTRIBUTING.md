# Contributing to SHM

Thank you for your interest in SHM.

## Issues

Bug reports and suggestions are welcome as GitHub issues. Please leave memory contents, credentials and other private data out of them.

## Code contributions

SHM accepts code contributions only under a Contributor License Agreement (CLA) that grants SAIHM Project the right to license each contribution under this repository's licence and under any later licence of the project. Until that agreement is published in this repository, pull requests cannot be merged; please open an issue to propose a change.

## Security

Please do not report a suspected vulnerability in a public issue. Use GitHub's private vulnerability reporting for this repository instead.
